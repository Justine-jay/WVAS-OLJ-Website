# WVAS-OLJ-Website

Repository for the Wednesday Virtual Assistance Services OLJ Website project.

## Current Project Stage

Planning and UI/UX Design

## Project Documentation

- `docs/requirements` - Contains the finalized system requirements, features, and user roles.
- `docs/system-flow` - Contains the HR, Client, and VA/Job Seeker workflow diagrams.
- `docs/wireframes` - Contains the Figma wireframe link and UI design references.

## Current Users

- HR
- Client / Employer
- VA / Job Seeker

## Team Collaboration

This repository is used by the team to organize, review, and update project documentation during the planning and development of the WVAS OLJ Website.
